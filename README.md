# IP Menubar

Страна и внешний IP в строке меню Mac. Статус связи, VPN на Mac или на роутере, обрывы VPN, утечка IPv6, трафик.

## Установка

macOS 13 или новее, Apple Silicon или Intel. Откройте Терминал и вставьте:

```sh
curl -fsSL https://github.com/nikitaaromanovv/ip-menubar/releases/latest/download/install.sh | sh
```

Команда скачивает последнюю версию, Та же команда обновляет приложение.

Без Терминала: скачайте [IP-Menubar.dmg](https://github.com/nikitaaromanovv/ip-menubar/releases/latest/download/IP-Menubar.dmg) и перетащите приложение в «Программы». При первом запуске macOS попросит подтверждение: «Системные настройки → Конфиденциальность и безопасность → Все равно открыть».

Автозапуск: «Настройки → Запускать при входе в macOS».

## Возможности приложения

- Страна и IP в строке меню, статус связи: стабильна, нестабильна, нет связи
- Российские и зарубежные ресурсы проверяются отдельно
- VPN на этом Mac, на роутере, частично, утечка IPv6
- Обрывы VPN с выходом напрямую, счетчик за 24 часа
- Проверка VPN по кнопке: сертификаты, HTTP, DNS, вход и выход, MTU
- Трафик за сегодня, 7 и 30 дней, месяц, год, любой период

## Данные

Приложение ничего не отправляет о вас. Запросы идут только к проверочным сервисам: yandex.ru, gstatic.com, ipify.org, ipwho.is, при проверке VPN также к dns.google, cloudflare-dns.com и нескольким крупным сайтам. Эти сервисы видят IP запроса. История и трафик хранятся на Mac.

## Удаление

Завершите приложение и удалите его из «Программ». Данные: `~/Library/Application Support/IP Menubar`.
